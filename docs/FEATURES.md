# ARPIARES Learning – Project Features

## Project Overview

ARPIARES Learning is an AI-Powered Learning Management System designed to help students learn, practise and track their academic progress.

The project combines two main tracks:

- Track A: Learning Management System (LMS)
- Track B: AI Quiz and Flashcard Generator

## Track A – Learning Management System

### Student Features
- Student registration and login.
- Browse available courses.
- Enrol in courses.
- View lessons and learning materials.
- Mark lessons as completed.
- Track course progress.
- Attempt quizzes and view scores.
- Receive a course completion certificate.

### Instructor Features
- Instructor registration and login.
- Create and manage courses.
- Add, update and delete lessons.
- Organise course content into sections.
- Create quizzes.

## Track B – AI Quiz and Flashcard Generator

### Main Features
- Add or paste study notes.
- Generate multiple-choice questions (MCQs).
- Generate flashcards from study material.
- Display correct answers and explanations.
- Calculate quiz scores.
- Review incorrect answers.
- Save quiz and flashcard history.
- Practise weak topics again.

## Technology Stack

- HTML – Website structure.
- CSS – Website design.
- JavaScript – Website interactions.
- Python – Backend programming.
- FastAPI – Backend web framework.
- SQLite – Database.
- Free and open-source AI tools – AI features, subject to available hardware and tool limitations.

## Project Goal

To build a beginner-friendly, functional learning platform that combines course management, progress tracking and AI-assisted practice.
