# ARPIARES Learning

### AI-Powered Learning Management System

**Learn smarter. Practise better. Grow further.**

ARPIARES Learning is a student-focused learning platform that aims to combine course management, learning progress tracking, quizzes and AI-generated flashcards in one application.

## Project Overview

This project combines two development tracks:

- **Track A – Learning Management System (LMS):** Manage courses, lessons, student enrolments and learning progress.
- **Track B – AI Quiz and Flashcard Generator:** Generate practice questions and flashcards from study notes.

## Planned Features

### Track A – Learning Management System

- Student and instructor registration and login.
- Course creation and management.
- Course sections and lessons.
- Student course enrolment.
- Lesson completion tracking.
- Course progress dashboard.
- Quizzes and score calculation.
- Course completion certificates.

### Track B – AI Quiz and Flashcard Generator

- Add or paste study notes.
- Generate multiple-choice questions (MCQs).
- Generate flashcards.
- Display correct answers and explanations.
- Calculate quiz scores.
- Review incorrect answers.
- Practise weak topics again.
